# World Rules

Drop your novel's canon here. Every agent in the pipeline reads **all files in
this folder** and treats them as hard constraints before doing anything.

Suggested files (name them however you like — the agents read the whole folder):

- `bible.md` — premise, themes, tone, the big picture
- `characters.md` — who they are, wants, voices, what they know and don't
- `world-rules.md` — how the world works: magic/tech systems and their costs,
  physical/social laws, what is and isn't possible
- `timeline.md` — canonical events and their order
- `style-guide.md` — POV, tense, register, banned words/items, content limits
- `continuity.md` — established facts that must never contradict

The more specific these are (especially costs, limits, and "forbidden" items),
the stronger the `forbidden_items` rails that flow through the whole pipeline.
This folder is currently empty except this README — upload your files and the
agents will pick them up automatically.
